# 大禹 · 轻喜剧风格预设（qing-xiju）

第三个**可运行的风格 preset 样例**，与 [古言权谋](../guyan-quanmou/README.md)、[硬科幻](../hard-scifi/README.md) 构成完整对比三角，验证大禹「多风格 = 整包配置切换，不改代码、不训练模型」的机制。

> 选轻喜剧是因为它的专属红线（苦情虐心）恰好是另外两包的合法区，而它放开的现代口语又恰好是古言包的红线——这种交叉差异最能证明每个 preset 都是独立的判定体系。

## 它改了什么（四包对比）

| 配置面 | 默认（网文爽文） | 古言权谋 | 硬科幻 | 轻喜剧 |
|---|---|---|---|---|
| `meta.display_name` | 大禹 | 大禹·古言权谋 | 大禹·硬科幻 | 大禹·轻喜剧 |
| 专属 L1 红线 | 可复现命令/内部标注 | 现代词、阿拉伯数字、感叹号章名、真实朝代影射 | 玄学词、伪科学 | **苦情虐心套路（melodrama_leak）** |
| 现代口语/网络词 | 合法 | **禁（fatal）** | 合法 | **合法且鼓励** |
| `classifier` | AI 味/油腻词 | + 古言语域跑偏 | + 技术万能/设定崩坏 | + 强行煽情说教/毒舌越界 |
| `anti_drift` | 冷感/炸裂漂移 | 恋爱脑/计谋无代价 | 技术万能/设定失守 | 强行煽情/毒舌越界/笑点枯竭/基调塌陷 |
| `pacing_signals` | 成交/打脸/震惊 | + 收网/廷争/构陷 | + 验证/点火/故障/悖论 | + 笑死/翻车/社死/真香/破功 |
| `positioning_enums` | 打脸碾压/解谜智性… | 布局收网/智性博弈… | 技术碾压/硬核解谜… | 反套路/误会化解/社死现场/毒舌反杀 |
| `rubric` | 人设30/结构25/连续20/文字25 | 人设30/权谋逻辑30/… | 人设20/科学自洽30/硬核质感30 | 人设25/笑点结构30/连续20/分寸25 |
| `word_bands` | 冷感/炸裂/通用 | + 权谋档（慢热） | + 硬核档（偏大） | + 轻快/爆笑档（偏小） |
| `prompts.md` | 网文写作铁律 | 半文半白、谋略有代价 | 科学自洽、反玄学 | 笑点靠反差、苦情是毒、吐槽对事不对人 |

## 能力边界（诚实说明）

| 风格体征 | 归属 | 例子 |
|---|---|---|
| 可计算 | L1/L2 规则（本包 rules.yaml） | 苦情套路词、强行煽情句式、说教结尾、毒舌越界词、笑点/翻车信号词 |
| 半可计算 | 弱信号（suspect + 证据） | 冷场、讪讪地笑、突然严肃、梗老套 |
| 只能语义 | L3 prompt（本包 prompts.md，交调用方 AI） | 笑点成不成立、分寸好不好、喜剧人格是否立得住、会不会只剩闹剧 |

**规则扫不出"这个包袱响不响"** —— 和大禹一贯的边界一致：能规则化的做成 preset，笑点这种主观的东西必须交给 L3 语义评审与人类判断。L1 只能守住"别写成苦情戏"。

## 怎么用

`CDA_CONFIG_DIR` 在**进程启动时**读取（模块顶层加载），要在启动命令前设置：

```bash
pnpm build
export CDA_CONFIG_DIR=/绝对路径/novel-cda-mcp/presets/qing-xiju
node dist/index.js --doctor --json    # 应显示 大禹·轻喜剧 / 0.2.0-xiju.1 / healthy=true
node dist/index.js                     # stdio 模式，供写稿 Agent 挂载
```

`--doctor` 输出应见：

```
display_name: 大禹·轻喜剧
rule_version: 0.2.0-xiju.1
config_dir: .../presets/qing-xiju
```

不设 `CDA_CONFIG_DIR` 即用回默认网文包；指向别家 preset 互不影响。

### MCP 客户端配置示例

```json
{
  "mcpServers": {
    "novel-cda-xiju": {
      "command": "node",
      "args": ["/绝对路径/novel-cda-mcp/dist/index.js"],
      "env": {
        "CDA_CONFIG_DIR": "/绝对路径/novel-cda-mcp/presets/qing-xiju",
        "CDA_MCP_DATA": "/长期保留/无中文无空格/目录"
      }
    }
  }
}
```

## 验证

`test/regression.test.ts` 的 `多风格 preset · 轻喜剧` 测试块固化了 6 个断言（含**交叉反向验证**）：

1. preset 三件套齐全
2. 加载后 display_name/版本切换、规则一致性通过、4 个 prompt key 齐全
3. preset 的 doctor 健康（fail=0）
4. **苦情差异**：「吐血/心如刀绞/生离死别」文本在默认、古言、硬科幻三包均通过，轻喜剧包 `fatal=true`（`melodrama_leak`）
5. **交叉反向**：网络口语「手机/微信/186」在古言包 fatal、轻喜剧包合法
6. 三风格互不污染：轻喜剧包后切回硬科幻包仍是硬科幻规则

四包对同一批文本的判定矩阵：

| 文本 | 默认 | 古言 | 硬科幻 | 轻喜剧 |
|---|---|---|---|---|
| 玄学词（真气/金丹/筑基） | 通过 | 通过 | fatal | 通过 |
| 精确数据（137.5米/0.3%） | 通过 | 数字泄漏 | 通过 | 通过 |
| 现代词（手机/微信/186） | 通过 | fatal | 通过 | 通过 |
| 苦情（吐血/生离死别） | 通过 | 通过 | 通过 | **fatal** |

跑法：`pnpm test`（28 单元 + smoke 全绿）。

## 设计要点（三个 preset 的共同经验）

1. **保留通用基准判据**：`reproducible_command`、`internal_marker_leak`、`pacing_signals` 通用基准词、`word_bands.通用` 全部保留——doctor 自检样本依赖它们。
2. **风格红线放 L1，风格信号放 L2**：苦情词必须进 `hard_reject`（fatal），冷场/讪讪地笑这类放 classifier（suspect）——什么该硬拒、什么只提醒，是 preset 设计的核心判断。
3. **交叉差异比单向差异更有说服力**：轻喜剧放开的现代口语恰是古言的红线、轻喜剧禁的苦情恰是别包合法区——这种交叉证明每个 preset 是独立判定体系，而非简单叠加。
4. **权重/字数档随风格重排**：轻喜剧把权重压在"笑点结构 30"、字数档往下调（轻快/爆笑偏小）——这些配置本身就是风格宣言。

新增风格见 [主 README 的多风格章节](../../README.md#多风格预设preset) 与 [古言 preset README 的「如何新增」](../guyan-quanmou/README.md#如何新增一个风格-preset)。
