## 补丁1 · 定位决策卡增加两项

```yaml
原定位决策卡（01 号）缺少的关键维度:

  性别向: 男频 / 女频 / 无性别
  情感契约: 读者为什么追？
    ∈ {爽 / 解谜 / 共鸣 / 治愈 / 陪伴}

为什么重要:
  男频与女频是两套完全不同的情感契约。
  漏掉性别向，很容易写出"男频骨架+女频皮"的畸形产物。
  例: 女频写成"毒妃打脸文"= 男频爽点 + 女频外壳（低级）
```

## 补丁2 · 爽点类型必须先定义（禁止沿用上一本）

```yaml
原问题:
  爽点库默认"打脸/碾压/反杀"（男频默认）
  → 女频直接套用会变成低级的"打脸爽文"

补丁: 开新书第一步，从五类里选一个（可主次搭配）:

  1. 打脸碾压型（狂臣）: 即时满足，反派当场崩溃
  2. 解谜智性型（隙者）: "原来还能这样"
  3. 无声反杀型（默者）: 延迟满足，反派事后才知道
  4. 清醒退出型（宴者）: "我不要了" —— 女频核心
  5. 情感共鸣型（通用）: 情绪浓度驱动，读者为关系而追

规则:
  □ 每本书开工前必须明确爽点类型
  □ 爽点库（07 号类文件）按选定类型重新填充
  □ 禁止直接复制上一本的爽点库
```

## 补丁3 · 反派类型扩展为三类

```yaml
原方法论: 敌人套娃（小BOSS → 大BOSS → 终极存在）
问题: 撑不住女频/文艺向——反派可能根本不是"人"

扩展为三类:

  A · 具象敌人（可打倒）:
     权臣、BOSS、反派组织
     → 打完即过，撑不起最长篇

  B · 规则（可理解）:
     规则降临、制度、系统
     → 理解它、利用它（隙者）

  C · 结构（不可打倒，只能离开）:   ★ 新增
     礼教、贤良标准、社会规训
     特征: "没有凶手的悲剧"
           ——伤害你的人，都觉得自己没错
     → 打不倒，只能"退出"（宴者）

为什么 C 最重要:
  C 类才撑得起女频与文艺向长篇，
  且它天然符合"体系不公+目标递进"的最强冲突源公式。
  → 主角的目标不是"赢"，是"自由"
```

## 补丁4 · 周期全检增加"防冷漠"检测项

```yaml
问题（张力）:
  反 AI 味要求"禁抽象情绪、强制具体"
  但女频/治愈向需要情感浓度
  → 一味"具体"会让主角变冷漠

解法（不是妥协，是转换）:
  抽象情绪 → 具体物件/动作（保留浓度，去掉抽象）

  ✗ "她很痛"
  ✓ "她攥着旧帕子，指节发白"

  ✗ "他内心五味杂陈"
  ✓ "他在地铁上坐过两站，醒来时车厢空了"

新增检测项（周期全检必查）:
  □ 是否因追求"淡/具体"而失去情感温度？
  □ 主角对人（尤其弱者）是否有真实的护短行为？
  □ 是否还有"让读者想哭"的时刻？
  □ 感情线是否还有真实流动（非工具化）？
```
