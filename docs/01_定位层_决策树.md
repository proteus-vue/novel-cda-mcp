# 定位层 · 决策树（决定生死的第一步）

> **这一层错了，后面四层全白做。**
> 很多 AI 小说失败不是写得差，是一开始就选错了平台与改编方向。

---

## 一、三个必答问题（开工前）

```yaml
Q1 · 在哪卖？（平台决定规则）
  A. 番茄/七猫（免费，广告分成）
  B. 起点/创世（付费，订阅）
  C. 豆瓣/知乎（短篇，质感）

Q2 · 卖给谁？（受众决定代入门槛）
  A. 打工人（职场共鸣，代入门槛低）
  B. 学生/年轻男性（升级爽感）
  C. 女性向（情感/关系）

Q3 · 改成什么？（改编形态决定写作技巧）
  A. 3D 动画年番（需大场面/动作/奇观）
  B. 真人短剧（需表演空间/微表情/对话）
  C. 不改编（纯文字）
```

---

## 二、平台选择对照表

| 维度 | 番茄 | 七猫 | 起点 |
|---|---|---|---|
| 商业模式 | 免费+广告 | 免费+广告 | 付费订阅 |
| **未签约流量** | **无搜索（致命）** | 需确认 | 有 |
| 独家要求 | 签约即独家 | 签约即独家 | 独家 |
| 优势品类 | 都市、职场、爽文 | 战神、赘婿、玄幻 | 慢热、重设定 |
| 读者耐心 | 极低（3章定生死） | 低 | 较高 |
| 章名要求 | ≥5字，钩子强 | ≥5字，钩子强 | 可文艺，格调优先 |
| 日更要求 | 6000-9000字 | 6000-10000字 | 4000-6000字 |

### 三个致命陷阱

```yaml
陷阱1 · 番茄"不签约无搜索"
  后果: 无法"先试水看数据再决定"
  对策: 市场调研前置到投稿前 + 站外低成本验证钩子

陷阱2 · 独家陷阱
  后果: 不能"两边都发"比数据
  对策: 签约前问清合约类型/期限/解约条件
        + 用另一家 offer 做比价筹码

陷阱3 · 品类错配
  例: 把历史权谋投番茄（代入门槛高）
  对策: 默者（职场）→ 番茄；狂臣（历史）→ 七猫
```

## 三、改编形态决策（决定写作技巧）

```yaml
A · 3D 动画年番（狂臣、玄幻、历史）:
  需要: 大场面、动作戏、视觉奇观、角色辨识度
  技巧: 大场面四要素、镜头三段式、可截帧定格
  忌: 内心戏为主、无动作、场景单一
  对标: 斗破、凡人、仙逆

B · 真人短剧（默者、职场、都市、悬疑）:
  需要: 表演空间、微表情、对话张力、情感浓度
  技巧: 内心外化五手法、对白留白、声音设计
  忌: 依赖内心独白、抽象情绪
  优势: 成本低、场景天然、表演可承载内心

C · 不改编（纯文字）:
  可专注文字质感
  但仍建议保留"可画性"（未来可能有改编机会）
```

### 决策口诀

```yaml
有打斗/大场面/奇观 → 走动画（A）
靠对话/心理/关系   → 走真人剧（B）
先定改编形态，再写"影视化规范"
```

## 四、受众代入门槛评估（起量关键）

```yaml
代入门槛从低到高:
  1. 职场（几乎人人有经历）      ← 起量最快
  2. 校园/成长（人人经历）
  3. 家庭/婚姻（成年人经历）
  4. 都市异能（无经历，但好懂）
  5. 历史朝堂（无经历，门槛高）
  6. 玄幻修仙（完全架空，靠设定吸引）

洞察:
  《默者》（职场）代入门槛低于《狂臣》（历史）
  → 但《狂臣》"爽得痛快"弥补了门槛
  → 门槛低的赢在"共鸣深"，门槛高的赢在"爽得猛"
```

## 五、定位决策卡模板（开新书必填）

```yaml
项目名: （内部代号，守调性，如"默者"）
对外书名: （带钩子，如《被裁那天，我拿到了公司最高权限》）
平台: 番茄 / 七猫 / 起点
受众: （一句话，如"被裁过的打工人"）
代入门槛: 低 / 中 / 高
改编形态: 3D动画 / 真人短剧 / 纯文字
对标作品: （2-3 部，锚定预期）
核心情绪: （一句话，如"老实人按规矩掀桌"）
差异化: （唯一不同，如"反击走流程不走拳头"）
目标体量: （如 400 章 100 万字）
日更计划: （如 6000-9000 字/天）
```

## 六、一句话总结

> **定位层是"Ship Before Build"——先想清楚卖给谁、改成什么，再动笔。**
> 平台决定规则，受众决定门槛，改编决定技巧。
> **这层偷懒，后面四层都是在给错误方向加速。**
