# 执行层 · 反 AI 味与反机械感

> **两个不同的病，要分开治。**
> AI 味 = 抽象（用概念替代感知）
> 机械感 = 均匀（一切都可预测）

---

## 一、AI 味的本质（诊断）

```yaml
洞察: AI 味的本质是【用抽象概念替代具体感知】

因为 LLM 训练目标是"概括"，
所以它天然倾向输出【总结性、抽象性、对称性】的表达。

三类典型症状:
  症状1 · 抽象情绪:
    "他内心五味杂陈" / "意味深长地" / "百感交集"
  症状2 · 总结升华:
    "或许，这就是成长的代价吧" / "这，就是命运"
  症状3 · 对称句式:
    "不是A，而是B"（一章超 2 次即过量）
```

---

## 二、反 AI 味：强制具体（药方）

### 2.1 抽象 → 具体的四把钥匙

```yaml
钥匙1 · 物件承载（最推荐）:
  ✗ "他很疲惫"
  ✓ "他在地铁上坐过两站，醒来时车厢空了"

钥匙2 · 具体动作:
  ✗ "他下定决心"
  ✓ "他关掉命令行，把保温杯拧紧，站起来"

钥匙3 · 具体数字:
  ✗ "他背负着沉重的房贷"
  ✓ "还剩一百八十六个月"

钥匙4 · 个体反应（替代群体反应）:
  ✗ "全场震惊"
  ✓ "左边那个御史的笏板掉了"
```

### 2.2 红黄牌词表（可量化检查）

```yaml
红牌词（一章 ≥2 次即超标，必须删）:
  仿佛 / 似乎 / 在这一刻 / 五味杂陈 / 值得一提的是 /
  某种意义上 / 不由得 / 莫名

红牌句式:
  "不是A，而是B"  → 一章 ≤2 次
  "这，就是XX"    → 一章 ≤1 次（且只在名场面）
  破折号          → 一章 ≤3 次
  段末升华        → 全书 ≤5 次

油腻词（爽文专用，一票否决）:
  狂妄一笑 / 嘴角勾起冷笑 / 区区也配 /
  全场震惊 / 气势如虹 / 眼中杀意凛然
```

### 2.3 项目专属要求（每本书不同）

```yaml
默者（冷感）:
  - 禁止感叹号
  - 允许"废话"（"这个需求排期到下周"）
  - 允许不升华（事件结束就结束）
  - 用具体替代抽象

狂臣（炸裂）:
  - 炸裂靠"动作与声音"，不靠形容词
  - 围观者反应必须具体（非统一"全场震惊"）
  - 允许短句堆砌（节奏快）
```

## 三、机械感的本质（诊断）

```yaml
洞察: 机械感来自【均匀】，不是来自【规则多】

三个典型:
  1. 每章恰好 2500 字      → 机器排的
  2. 每章都带钩子章名      → 疲劳廉价
  3. 每个角色说话都是机锋  → 不真实

反直觉结论:
  规则越多 ≠ 越机械
  关键是规则要【分层 + 浮动 + 允许例外】
```

## 四、反机械感：不匀称（药方）

### 4.1 字数浮动（废止"严格字数"）

```yaml
❌ 旧: 每章严格 2500 字
   问题: 情绪写完了还差字数 → 注水（正是 AI 味来源）
        高潮刚起来字数到了 → 截断

✅ 新: 按类型设区间，"卡点"结束
   静场章: 1200-2200（默者）/ 1500-2500（狂臣）
   常规章: 2200-3200 / 2500-3500
   反击章: 2800-4000 / 3200-5000
   高潮章: 3500-5500 / 4500-7000
   极短章: 800-1500（每卷 1-2 次）

铁律: 宁可短，不可注水；高潮未写完允许超上限
结束条件: 情绪走到"卡点"，不是字数达标
```

### 4.2 章名分层（废止"全钩子"）

```yaml
前 30 章:   100% 钩子（抢读者）
常规章:     ~55% 钩子
名场面章:   ~15% 短名词（内容够炸，标题不喊）
情感章:     ~10% 克制短句（沉默也是力量）

口诀:
  这一章是"最有名的场面"？→ 是，用短名；不是，用钩子
  前 30 章？→ 一律钩子，不管是不是名场面

反例:
  ✓ "刀落"（短而重）
  ✗ "刀落，满殿无一人出声！"（力道被稀释）
```

### 4.3 对话不匀称

```yaml
❌ 机械: 每个角色说话都带机锋、都很有深度
✅ 真实: 有人说话带废话、有人打断、有人答非所问

技巧:
  - 允许"无信息量对话"（真实感）
  - 允许角色说错话/被误解
  - 允许沉默（对话中的留白）
```

## 五、听书（TTS）格式规范

```yaml
三轨分离（最重要）:
  旁白: 无引号
  对白: ""（中文双引号）
  独白: 『』且单独成段

一人一段（音色分配）:
  ✗ "A说..."B说..."（挤一段，TTS 一个音色读完）
  ✓ 每个角色说话独立成段

数字可读化（TTS 杀手）:
  005 → 零零五    2/5 → 五分之二
  186 → 一百八十六  N+1 → N加一
  代码 → 泛化（"删除命令"，规避合规+听书双重风险）

禁止:
  引号嵌套 / 括号大段 / 引号不闭合 /
  破折号连用(>3) / 无标点长段 / 颜文字
```

## 六、影视化：可画 / 可演

```yaml
核心: Show Don't Tell 不是修辞，是改编刚需

动画路径（大场面）:
  大场面四要素: 空间尺度 / 人数规模 / 光影天气 / 声音
  镜头三段式: 远景(规模) → 中景(主角) → 特写(定格)
  动作四拍: 起(对方) → 承(主角) → 转(反击) → 合(定格)

真人剧路径（内心戏）:
  内心外化五手法:
    1. 物件承载（手摩挲保温杯）
    2. 微表情（眼皮抬了一下又垂下）
    3. 动作替代（光标停在命令上没敲）
    4. 环境投射（弹窗一个接一个）
    5. 对白留白（只回一个"嗯"）

声音设计（两路径通用）:
  炸点后写"静 + 一个细声"
  例: 刀落。满殿没人出声。殿外，雪压断了一根枯枝。
```

## 八、一句话总结

> **AI 味用"具体"治，机械感用"不匀称"治。**
> 强制物件、动作、数字、个体反应；
> 字数浮动、章名分层、对话留白。
> **当一切都不那么"整齐"，文字就有了人味。**
