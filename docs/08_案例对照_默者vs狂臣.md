# 案例对照 · 默者 vs 狂臣（同一方法论的两个极端应用）

> **同一套 CDA 方法论，产出两本气质完全相反的书——**
> 这证明了方法论的"可复制性"：换内容，不换结构。

---

## 一、为什么做两个相反的项目

```yaml
初衷: 分散风险（番茄 vs 七猫，双平台对赌）

意外收获（更重要）:
  两个项目互相"定义"了对方。
  单本书说"我要冷感"，模型不知道边界；
  有了狂臣做对照，"默者 = 不是狂臣"立刻变得可检查。

这是本方法论最有价值的发现:
  【对立面定义法】——用"不是什么"定义调性
```

## 二、全景对照表

| 维度 | 默者（冷感/职场） | 狂臣（炸裂/历史） |
|---|---|---|
| **平台** | 番茄 | 七猫 |
| **改编形态** | 真人短剧 | 3D 动画年番 |
| **项目名/书名** | 默者 / 《被裁那天…》 | 狂臣 / 《满朝文武…》 |
| **主角** | 王默（31岁运维） | 萧彻（24岁归京质子） |
| **代入门槛** | 低（打工人共鸣） | 高（历史架空） |
| **爽点类型** | 延迟满足 | 即时满足 |
| **反击方式** | 改数据库 / 发邮件 | 拔刀 / 掀桌 |
| **反派感知** | 无感知（事后才发现） | 当场崩溃 |
| **章末钩子** | 留白 / 物件 | 炸点 / 金句 |
| **金句风格** | 陈述句，越轻越重 | 挑衅/反问，越短越狠 |
| **感叹号** | 禁用 | 可用（每卷≤3） |
| **伏笔编号** | F#（F1-F35） | G#（G1-G38） |
| **章名公式** | 数据/系统语言/无声反差 | 挑衅/动作/数字反差 |
| **名场面** | 按流程 / 不换 / ping | 刀落 / 倒戈 / 冲阵 |
| **核心金句** | "我不是钥匙，我是用钥匙的人" | "我本桀骜，何须隐忍" |
| **主题** | 规则可被修复 | 掀桌者最终扶正桌子 |

## 三、同一场景的两种写法（最直观的对照）

```yaml
场景: 主角被当众羞辱

默者（冷感）:
  "你这个月的绩效，不合格。"
  孙总监整了整领带。
  王默没抬头。
  "嗯。"
  → 压抑、无声、读者替他憋着

狂臣（炸裂）:
  "北境回来的野种，也配姓萧？"
  裴琰挑着眉。
  萧彻看了他一眼。
  "你刚才说什么？"
  → 挑衅、对峙、读者等他掀桌
```

```yaml
场景: 反击完成

默者:
  他把报销科目从部门经费改成个人借款。
  关掉窗口。
  起身去接热水。
  → 无人察觉，反派三天后才知道

狂臣:
  他一脚踹翻案几。
  茶盏碎在裴衍脚边。
  满殿没人说话。
  → 当场定格，满场寂静
```

```yaml
场景: 全书终章

默者:
  "系统正常。晚安，修系统的人。"
  → 温柔、克制、人与系统告别

狂臣:
  "只有一个，掀桌子的人。"
  → 传说、浪漫、精神不灭
```

## 四、方法论层面的三个验证

### 验证1 · 结构可复用（换内容，不换骨架）

```yaml
两本书的结构完全同构:
  - 都是四卷 400 章 100 万字
  - 都是"立/升/转/合"四卷架构
  - 都是每章有暗爽、每3章有明爽
  - 都是伏笔编号管理
  - 都是"每章=1集"

差异只在"内容层":
  - 人设不同
  - 金手指不同
  - 调性不同
  - 词表不同

结论: 骨架可复用，内容需定制
```

### 验证2 · 对立定义有效（防串味）

```yaml
实测:
  写默者时，prompt 里写明"禁止嚣张/禁止当场碾压"
  写狂臣时，prompt 里写明"禁止隐忍/禁止走流程"

效果:
  两本书调性拉得很开，没有互相污染
  且"防对方味"成了最高效的评审项
  （比"检查是否克制"这种模糊指令有效得多）
```

### 验证3 · 批量生产可行

```yaml
第 1 本（默者）: 从零摸索，慢
第 2 本（狂臣）: 复用框架，快很多
  - 文件结构直接复制
  - 只需替换: 人设/金手指/章纲/词表
  - 基础设施（评审/格式/字数/SOP）原样复用

结论: 第 3 本书的建置成本会进一步降低
```

## 五、给后续新项目的启示

```yaml
1. 新项目要主动找"对立面":
   已有默者(冷) + 狂臣(炸) →
   下一个可以找:
     - 温馨治愈（反爽文）
     - 群像史诗（反单主角）
     - 悬疑反转（反明牌）

2. 文件结构直接复制:
   00-18 号文件框架复用
   只改: 人设卡 / 金手指 / 章纲 / 词表

3. 词表必须项目专属:
   冷感词 ≠ 炸裂词 ≠ 治愈词
   → 禁止跨项目复用词表（会串味）

4. 编号必须独立:
   F# / G# / H# ... 每本书一套
   → 防止伏笔串线
```

## 六、一句话总结

> **默者证明"冷感"能立住，狂臣证明"炸裂"能立住，**
> **两者对照，证明了同一套方法论能产出完全相反的气质。**
> 这就是"可复制"的最好证据：**换内容，不换结构。**
